# 🖋️ 마음 필사(筆寫) - Gemini AI 기반 A4 필사 노트 웹 앱

마음을 차분하게 가라앉히고 성찰을 돕는 **A4 용지 1장 분량의 고품격 필사(筆寫) 콘텐츠 생성 및 보관 앱**입니다.

## ✨ 주요 기능

1. **원클릭 필사 콘텐츠 생성**:
   - 클릭 한 번으로 시, 소설 명문장, 인생 에세이, 사색 여행기, 위대한 사상가의 철학 명언 중 하나를 생성합니다.
   - A4 용지 1장에 손글씨로 필사하기 최적화된 분량(약 700~1,100자)으로 정갈하게 구성됩니다.
   - 장난스럽거나 가벼운 문구를 엄격히 배제하고 깊은 울림과 격조를 갖춘 문장만 엄선합니다.

2. **중복 없는 콘텐츠 보관 (SQLite 파일 DB)**:
   - 생성된 모든 필사 글은 로컬 파일 기반 데이터베이스(`transcription.db`)에 안전하게 저장됩니다.
   - 본문 고유 해시(SHA-256) 검증 및 이전 생성 목록 프롬프트 피드백을 통해 **중복 생성을 원천 차단**합니다.

3. **날짜별 아카이브 및 탐색**:
   - 좌측 사이드바에서 날짜별로 분류된 필사 아카이브를 클릭하여 언제든 과거의 글을 다시 읽고 필사할 수 있습니다.

4. **A4 용지 최적화 뷰어 & 인쇄 기능**:
   - 실제 원고지/양질의 종이 느낌을 살린 A4 비율 뷰어 디자인.
   - **`🖨️ A4 인쇄`** 클릭 시 사이드바 및 버튼이 자동으로 숨겨지며, 정확히 A4 1장에 맞춤형으로 출력됩니다.
   - 키보드로 직접 따라 치며 연습할 수 있는 **`✍️ 필사 연습 모드`** 제공.

5. **Gemini AI 연동 & 오프라인 보관함 지원**:
   - Google AI Studio API 키를 등록하면 Gemini 2.5 Flash / 1.5 Flash 모델과 실시간 통신하여 무한한 글을 생성합니다.
   - API 키가 없어도 내장된 엄선 명문장 보관함(윤동주, 헨리 데이비드 소로, 생텍쥐페리 등)을 통해 즉시 사용 가능합니다.

## 🚀 실행 방법

### 방법 1: 실행 스크립트 이용 (권장)
터미널에서 아래 명령을 실행하면 서버가 켜지고 기본 웹 브라우저가 자동으로 열립니다.

```bash
cd /Users/slux78/.gemini/users/user1/handwriting_app
./run.sh
```

### 방법 2: 파이썬 직접 실행
외부 패키지 설치 없이 Python 3 내장 라이브러리만으로 즉시 구동됩니다.

```bash
cd /Users/slux78/.gemini/users/user1/handwriting_app
python3 app.py
```
브라우저에서 [http://localhost:8080](http://localhost:8080)으로 접속하세요.

## ⚙️ Gemini API 키 설정

1. 웹 화면 좌측 하단의 **`⚙️ Gemini API 설정`** 버튼을 클릭합니다.
2. [Google AI Studio](https://aistudio.google.com/app/apikey)에서 무료로 발급받은 API 키를 입력하고 저장합니다.
3. 또는 터미널에서 환경변수를 설정하고 실행하셔도 됩니다:
   ```bash
   export GEMINI_API_KEY="your_api_key_here"
   ./run.sh
   ```
